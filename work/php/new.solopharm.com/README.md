# Описание
## Инструкиция по сборке:
1. Сделать backup проекта и dump базы данных, перенести на новую систему.
2. По необходимости обновить vendor командой *composer update* в корне сайта, так же запустить команду *php artisan vendor:publish --tag=lfm_public*.
3. В директории frontend запустить команду *yarn upgrade*.

## Настройки
- Доступы к базе данных и основные настройки проекта находятся в файле **.env**.
- Файл настройки админки **/config/moonshine.php**.

## Структура 
- Структура основана на php фреймворке <a href="https://laravel.com/">Laravel</a> и админки <a href="https://moonshine.cutcode.dev/">Moonshine</a>.
- Структура базы данных описана в файлах миграции **/database/migrations**.
- Директория **frontend** предназначена для сборки фронтенда, блоки подключаются из дериктории **resources/views**.
- **/app/Services** берет на себя выполнения некоторых действий, что б не перегружать работу контролеров.
- **/database/admindata** данные из *json* файлов используются для создания моделей, миграций и страниц в админке.

## Технологический стек
- PHP 8.2
- Laravel 10.2
- Moonshine 1.53
- Teachart frontend-api 5.0
- Intervention-image 2.7

## Инструкции
1. Для быстрого создания backend данных для новой сущности , необходимо переименовать директрию **stubsExp** в **stubs**, создать *json* файл, в директории **/database/admindata** с названием соответствущим с названием таблицы в БД и заполнить его нужными данными по аналогии с другими файлами в этой директории. Затем выполнить команду в теримнале *php artisan make:admindata {название таблицы} {название модели}*. Выполнить миграцию.

2. Для сборки проекта в директории **/frontend** выполнить команды *yarn build-dev* или *yarn build-prod*.
3. Для быстрого форматирования файлов стилей по стандартам *yarn format-style* в директории **/frontend**.
4. Для быстрого форматирования файлов скриптов по стандартам *yarn format-script* в директории **/frontend**.
5. Формирование *sitemap.xml* производится по средствам запуска команды *php artisan make:sitemap*. Так же формирование нового *sitemap.xml* производится в ночь с воскресения на понедельник, путем использования *crontab*.
6. После добавлении или редактировании записи в админке , необходимо сбрасывать *cache* *{корень сайта/admin}* кнопка *очистка кэша*.
