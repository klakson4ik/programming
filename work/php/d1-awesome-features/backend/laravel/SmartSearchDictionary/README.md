# Компонент для создание словаря "умного" поиска
## Описание компонента
Компонент создает словарь лемм слов, беря в качестве источника базу данных.

## Правила
- исключаются местоимения, междометия, частицы, союзы [русского](./SDirectoryService/data/exclude-ru.php) и [английского](./SDirectoryService/data/exclude-en.php), так же можно добавить любые слова в [исключения](./SDirectoryService/data/exclude-custom.php).
- Обрезаются HTML теги
- Слова с символом ['/'](./SDirectoryService/DictionaryService.php#L70) не добавляются


### Конфигурационный файл
Файл содержит основные настройки, влияющие на корректность, точность и функциональность поиска. Доступны для указания следующие параметры:
- `string modelsNamespace` - пространство имён моделей (По умолчанию: `App\Models`)
- `string dictionariesPath` - путь к папке со словарями относительно расположения файла `index.php` (По умолчанию: `../resources/dictionaries`)
- `string fullDictionaryName` - название файла полного словаря (По умолчанию: `words.json`)
