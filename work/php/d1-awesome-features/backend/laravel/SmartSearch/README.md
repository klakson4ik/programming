# Компонент "умного" поиска для фреймворка laravel
## Описание компонента
Компонент представляет собой совокупность классов и настроек, с помощью которых происходит поиск текста в базе данных. Имеется множество настроек модуля, которые устанавливаются в файле `config/search.php`

### Алгоритм работы поиска
1) Полученная строка проверяется на пустоту и размер. Если она пустая или её длина больше указанного размера, то вернётся ошибка.
2) Строка разбивается на слова с учетом дефисов.
3) Слова сортируются по языкам.
4) Формируется ранжированный массив.
5) Формируется массив с дополнительной информацией о словах, сортируются и отбрасываются лишние.
6) Если разрешено использование индексирования, то производится поиск слов в таблице индексов.
7) Производится поиск по моделям исключая результаты, полученные из индексной таблицы.
8) Результаты поиска возвращаются в виде ассоциативного массива, где ключами выступают названия моделей.

### Конфигурационный файл
Файл содержит основные настройки, влияющие на корректность, точность и функциональность поиска. Доступны для указания следующие параметры:
- `bool useIndexing` - если установлен `true`, тогда будет использоваться индексирование результатов поиска (По умолчанию: `true`)
- `int|bool maxSearchSize` - указывает максимальный размер строки для поиска. Если переданный текст будет превышать его, то вернётся ошибка. Если установлен false, то ограничения не будет (По умолчанию: `false`)
- `int|bool minWordRange` - указывает минимальный ранг слова, который требуется для его участия в поиске. Если установлен `false`, то учитываться будут слова всех рангов (По умолчанию: `false`)
- `int|bool maxWordsCount` - указывает максимальное число слов в группе, по которым будет произведён поиск. Если установлен `false`, то учитываться будут все слова (По умолчанию: `5`)
- `string modelsNamespace` - пространство имён моделей (По умолчанию: `App\Models`)
- `bool useLemmaComparison` - если установлено значение `true`, то найденные слова будут дополнительно проверяться на соответствие лемме исходного слова (По умолчанию: `false`)
- `bool addPartialResults` - если установлено значение `true`, то к результатам "умного" поиска будут добавлены результаты частичного поиска (По умолчанию: `false`)
- `bool useCorrectionDictionaries` - если установлено значение `true`, то введенные слова будут проверяться на корректность по словарям (По умолчанию: `false`)
- `string dictionariesPath` - путь к папке со словарями относительно расположения файла `index.php` (По умолчанию: `../resources/dictionaries`)
- `int differentsCount` - максимальный размер расстояния Левенштейна, при которой происходит исправление опечатки
- `bool useFullDictionary` - если установлен `true`, то будет использован полный словарь с перечнем всех слов. Иначе словарь определяется по первой букве слова. Включение необходимо для предусмотрения корректировки опечатки в первой букве слова (По умолчанию: `false`)
- `string fullDictionaryName` - название файла полного словаря (По умолчанию: `words.json`)
- `array|null profiles` - Профили с граммемами для ранжирования. Указываются для каждого языка отдельно в формате `'ГРАММЕМА' => ЗНАЧИМОСТЬ`. Если не указывать, то берутся автоматически (По умолчанию: `null`)
- `array levenshteinCosts` - указание стоимости вставки, замены и удаления для алгоритма Левенштейна. (По умолчанию все единицы)
- `array models` - перечень всех моделей с полями, по которых производится поиск. У каждой модели имеются следующие параметры:
    - `array fields` - перечень возвращаемых в результате полей модели
    - `array searchFields` - перечень полей модели, по которым производится поиск
	- `array fulltextSearchFields` - перечень полей модели, по которым производится полнотекстовый поиск средствами mysql (поля должны быть текстового типа: `VARCHAR`, `TEXT`)

### Класс SearchService
Класс выполняет поиск запроса в базе данных. Имеются следующие методы: 
- `public search(string): array` - основной используемый метод. На вход передается строку запроса по которой производится поиск в базе данных. Возвращает массив найденных результатов или массив с информацией об ошибке, если таковая произошла.
- `private getRangedArr(array): array` - генерирует ранжированный массив слов. На вход передается массив слов. Возвращает сортированный массив с указанием рангов. Ранги определяются по профилю и зависят от части речи слова.
- `private prepareWordsInfo(array): array` - подготавливает дополнительную информацию о словах и исправляет опечатки. На вход передается ранжированный массив слов. Возвращает массив слов, лемм и псевдокорней.
- `private breakString(string, bool): array|bool` - разбивает строку на слова. На вход первым параметром получает строку, вторым - булев указатель использования фильтра html-тегов. Возвращает массив слов строки или `false` в случае ошибки.
- `private searchInModels(array, array): array|bool` - производит поиск по моделям в базе данных. На вход первым параметром получает массив слов с леммами и псевдокорнями, вторым - список id исключаемых из поиска моделей. Возвращает массив с результатами поиска или `false` в случае ошибки.
- `private searchInIndex(array): array|bool` - производит поиск слов среди проиндексированных. На вход передается массив слов с леммами и псевдокорнями. Возвращает массив с результатами поиска или `false` в случае ошибки.
- `private prepareModelData(array, array, array): array` - унифицирует результаты поиска, фильтрует массив в соответствии с заданными параметрами. На вход первым параметром принимает массив слов с их леммами и псевдокорнями, вторым - массив с информацией о модели, третьим - массив результатов поиска. Возвращает отфильтрованный и отсортированный результирующий массив.
- `private getCorrectedWord(string): string|bool` - исправление опечаток в слове с использованием словаря. На вход передается слово, которое необходимо проверить на корректность. Если указанного слова нет в словаре, но есть наиболее подходящее, которое можно получить путём правильных корректировок, то вернётся оно. Если слово есть(то есть никаких преобразований проводить не надо) в словаре или не найдено ни одного подходящего слова, то возвращается `false`
- `private levenshteinCustom(string, string, int, int, int): int` - аналог функции Левенштейна для кириллицы. Принимает те же параметры, что и оригинальная функция
<br><br>

### Класс MorphyService
Класс для получения информации о словах и их корректирования. Имеются следующие методы?
- `public getWordLanguage(string): string|bool` - выясняет язык слова по первой букве. На вход передается слово. Возвращает `ru` или `en`, если первая буква кириллическая или латинская соответственно или `false` в ином случае. Поддерживаются только 2 языка.
- `public replaceLangLayout(string): string|bool` - меняет раскладку текста на противоположную. На вход передается слово. Возвращает слово с другой раскладкой или `false`, если язык слова не соответствует указанным.
- `public sortByLanguages(array): array` - сортирует массив слов по языкам. На вход передается несортированный массив слов. Возвращает ассоциативный массив этих же слов, разбитых по языкам.
- `public getLemma(string): array|bool` - получает леммы слова. На вход передается слово. Возвращает массив лемм переданного слова или `false` в случае некорректной раскладки или при отсутствии лемм.
- `public getPseudoRoot(string): array|bool` - получает псевдокорни слова. На вход передается слово. Возвращает массив псевдокорней переданного слова или `false` в случае некорректно раскладки или при отстутствии корней.
- `public getWordForms(string): array|bool` - получает все формы слова. На вход передается слово. Возвращает массив форм слова или `false` в случае некорреткной раскладки или некорректного слова.
- `public getRange(string, array|bool)` - получает ранг слова в соответствии с профилем. На вход первым параметром передается слово, вторым - профиль(необязательный параметр). Возвращает целочисленный ранг слова.
<br><br>

### Класс IndexingService
Класс для работы с индексированием данных для ускорения поиска. Имеются следующие методы:
- `public setIndex(array)` - записывает индексированные данные в соответствующую таблицу. На вход передается массив с данными.
- `public getIndexed(string|array)` - получает индексированные данные по ключу. На вход передается строка или массив с ключами/ключом. Возвращает массив слов и моделей с `id` элементов, содержащих слова.
- `public updateIndexes(array)` - обновляет индексы в соответствии с переданным массивом. На вход получает массив с индексами и данными, которые необходимо обновить.
- `public clearIndex(string|array)` - очищает указанный индекс. На вход получает слово или список слов, индексы которых необходимо очистить.
- `public clearIdnexes()` - полностью очищает таблицу индексов.

## Установка компонента
Шаг 1. Установка библиотеки phpMorphy, которая позволяет получать основную информацию о словах.
```
composer require cijic/phpmorphy
```
Шаг 2. Перенос всех файлов в директорию проекта\
Шаг 3. В случае использования индексирования необходимо провести миграцию\
Шаг 4. Если планируется использование полнотекстового поиска средствами mysql, то необходимо установить полнотекстовые индексы на те таблицы и поля, которые будут использоваться. Например для поиска в таблице `search_table` по полям `name` и `description` необходимо использовать следующую команду:
```
alter table search_table add fulltext(name, description);
```
Шаг 5. Установка необходимых настроек в файле конфигурации\
Шаг 6. Создание экземпляра класса `SearchService` и вызов метода `search`
