# Модели для инфоблоков и HL блоков битрикс
Предоставляют простой доступ к часто требуемым операциям с hl/инфо блоками (find, select, update и т.д) с боллее удобным интерфесом, чем нативный битриксовый GetList и т.д.

Для работы нужно созадть класс, унаследовавшийсь от необходимой базовой сущности (hl блок - `HBlockModel.php`, инфоблок - `IBlockModel.php`). И обязательно указать свойство ```$code``` - символьный код сущности

Так же в классе `IBlockModel.php` есть методы для удобной работы с разделами инфоблока
