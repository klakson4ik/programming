# Поле в админке с произвольной дополнительной информацией.

## Описание
Добавляет в инфоблок пользовательское поле **Привязка у инфоблоку с выводом дополнительной информации**, по определеному шаблону выводит в элемент дополнительную информацию

## Инструкция 
Скопировать директорию IBlockFieldWithInfo в local/lib/Bitrix/PropertyFields
Добавить в инфоблок поле типа *Привязка у инфоблоку с выводом дополнительной информации*(может быть множественное), в настройках в разделе *дополнительные настройки* выбрать установить разделитель (по умолчанию ' | ') и выбрать поля или свойства для отоброжения например: *NAME, PROPERTY_EXAMPLE*.
Так же реализован метод выборки информации из Hihgloadblock шаблон **PROPERTY_EX:H:52:UF_NAME,NAME** - PROPERTY_EX - свойство, H - работа с highblock, 52 - id highblock, UF_NAME - выводить имя


Для реализации своего метода необходимо добавить шаблон в админку в настройки поля:

	- PROPERTY_EX всегда идет первым значением , свойство или поле от которго реализуется данный элемент
	- Второе  значение сопостовление названию метода
	- Разделитель значений в шаблоне ":"

## Пример

В метод PropertyAction::choice добавть выборку: значение шабона -> название метода и реализовать метод, который должен возращать строку

```php
private static function choice()
	{
		return match (self::$propArr[1]) {
			'H' => self::hBlockElem(),
		};
	}

```
