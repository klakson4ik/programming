# Работа медиабиблиотекой
Обретка над битриксовымы CMedialibItem, CMedialibCollection

возможности:

- получать элемент по id
- получать элементы по имени коллекции
- получать коллекцию по id
- получать коллекции
- получать коллекции в виде дерева
- обновлять элементы
- обновлять коллекции
- получать типы коллекции
- получать элементы по имени файла(в bitrix нет такого метода)
