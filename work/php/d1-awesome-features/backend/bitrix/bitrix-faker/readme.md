# Faker для Bitrix.TAO

В lib/Support/Abstract лежат абстрактные фабрики для следущих сущностей битрикса:
-HLBlock
-IBlock
-IBlockSection

Для создания фабрики нужно наследовать класс соотвествующей сущности.
Определить метод fields а также iblock_id или hlblock_id свойства сущности.
Вызов фабрики делается статичным методом new()
Метод create вызывает генерацию сущностей, с полями описанными в ее фабрике (метод fields).
Пример выозова описан в файле `/local/CLI/Faker.php`

В `lib/Support/` так же представленны демонстрационные фабрики:
-Brand фабрика элемента инфоблока
-Product фабрика для элемента и секции инфоблока, а так же для HL блока, в фабрике элемента показанно связываение сущностей
