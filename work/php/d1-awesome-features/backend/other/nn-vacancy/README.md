<h1 align="center">Преобразование вакансий норникель в SQL запрос</h1>

## Использование с помощью консольной команды

> Требуется php >=8.3

*не забудьте установть vendor зависимости*

Что бы начать положите файл c вакансиями в формате xlsx в директорию `/resource/input` <br/>
Убедитесь, что в exel файле только один лист <br/>
Запустите команду
```shell
php bin/cli.php vacancy
```
Далее:
* Укажите номер компании (id  втаблице)
