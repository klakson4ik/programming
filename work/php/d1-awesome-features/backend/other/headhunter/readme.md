# Модуль для работы с API headhunter'а
## Описание модуля
Модуль представляет собой класс, реализующий основные запросы для интеграции с hh. В конструктор передаются id работодателя, email, название продукта и его версия. 

Описание методов:
- `getVacancies` - Публичный метод. Получение списка вакансий работодателя. Метод не возвращает описания вакансий. Для их получения использовать метод `getVacancy`<br>
Параметры метода:
    - `int $areaId` - Необязательный параметр. Добавляет фильтр по городам, областям и странам.
    - `int $perPage` - Необязательный параметр. Устанавливает максимальное количество отображаемых записей на одной странице(за один запрос). Если не указывать, то по умолчанию будет установлено 20 записей
    - `int $page` - Необязательный параметр. Устанавливает страницу просмотра записей (Смещение `$page` * `$perPage`).<br>
    __Важно:__ отсчёт страниц происходит с нуля
    - `bool $allParams` - Необязательный параметр. Если установлен `true`, то функция вернёт дополнительные параметры (Общее число подходящих записей, количество страниц и пр.). Иначе вернёт только список вакансий<br>
- `getVacancy` - Публичный метод. Получение конкретной вакансии. Метод не возвращает требования и обязанности к вакансии. Для их получения использовать метод `getVacancies`<br>
Параметры метода:
    - `int $vacancyId` - Обязательный параметр. Устанавливает ID вакансии. Если не указан, будет возвращено `false`.
- `getCountries` - Публичный метод. Получение списка стран. Можно дополнительно указать фильтр<br>
Параметры метода:
    - `int|string $identifier` - ID, название страны или часть названия страны.
- `getAreas` - Публичный метод. Получение регионов(Стран, городов, областей и т.д.) или конкретного региона.
    - `int $areaId` - Необязательный параметр. ID региона. Если указан, то будет возвращена детальная информация по региону. Иначе список всех регионов.
- `getDistricts` - Публичный метод. Получение списка областей. Можно указать фильтр.<br>
Параметры метода:
    - `int $areaId` - Необязательный параметр. Если указан, то результат будет содержать все области региона `$areaId`
- `getEmployer` - Публичный метод. Возвращает детальную информацию по работодателю. Если для экземпляра класса не был указан `$employerId`, то вернёт `false`.
- `sendQuery` - Приватный метод. Отправляет запрос по указанному урлу.<br>
Параметры метода:
    - `string $url` - Обязательный параметр. Содержит URL запроса.

## Примеры использования
### Создание экземпляра класса
```php
$hh = new \App\Services\HHService(
    employerId: 71287,      // ID Работодателя
    email: 'test@test.test',// Email (Используется в заголовке запроса)
    productName: 'test',    // Название проекта (Используется в заголовке запроса)
    productVersion: '1.0'   // Версия проекта (Используется в заголовке запроса)
);
```
### Получение списка вакансий по региону с доп параметрами
```php
$hh->getVacancies(
    areaId: 92,     // ID региона
    perPage: 100,   // Число подгружаемых записей
    page: 0,        // Страница с записями
    allParams: true // Вернуть полный ответ с доп параметрами
);
```
### Получение и фильтрация стран
```php
$hh->getCountries(identifier: 'бел'); // Будут возвращены все страны, содержащие 'бел' в названии
$hh->getCountries(identifier: 113); // Будет вовзращена страна с ID 113
```
### Получение районов региона
```php
$hh->getDistricts(92); // Будут возвращены все районы региона с ID 92
```
